### 阶乘
在数学中，正整数的阶乘（英语：factorial）是所有小于等于该数的正整数的积，记作 $n!$
$$
n! = \prod_{k = 1}^n k
$$
定义 $0! = 1$

```cpp
// 预处理阶乘
using ll = long long;
const ll MOD = 1e9 + 7;
const int N = 1e6 + 5;
ll fact[N];

void getFact(){
    fact[0] = 1;
    for(int i = 1; i < N; i++){
        fact[i] = fact[i - 1] * i % MOD;
    }
}
```

### 双阶乘(Double factorial)
正整数的双阶乘表示小于等于该数的所有具相同奇偶性的正整数的乘积，即：
$$
\begin{cases}
    (2n - 1)!! = 1 \times 3 \times 5 \times \cdots \times (2n - 1)\\
    (2n)!! = 2 \times 4 \times 6 \times \cdots \times (2n)
\end{cases}
$$
奇数双阶乘
$$
(2k - 1)!! = \prod_{i = 1}^k (2i - 1) = \frac{(2k)!}{2^kk!}
$$

#### 从 n 个数中任取三个数的乘积之和

**高效算法（在线更新，推荐）**

一次遍历即可求出所有三元组乘积之和，无需存储全部 \( s_i \)：

```python
def sum_of_triple_products(s_list):
    sum1 = 0   # 单个 s 的和
    sum2 = 0   # 两两乘积之和 (i < j)
    sum3 = 0   # 三元乘积之和 (i < j < k)
    for s in s_list:
        sum3 += sum2 * s
        sum2 += sum1 * s
        sum1 += s
    return sum3
```

**原理**：  
- 当处理到当前的 s 时，`sum2` 已经保存了前面所有两两组合的乘积和；将其乘以 s 就得到了所有以当前 s 结尾的三元组乘积，累加到 `sum3`。  
- 然后更新 `sum2`：将前面所有单个元素的和 `sum1` 乘以 s，表示新增的包含 s 的两两组合。  
- 最后更新 `sum1` 加上 s 本身。

遍历一遍后，`sum3` 就是所有 \(i < j < k\) 的 \(s_i s_j s_k\) 之和。

---

**完整流程**

1. **预处理**：遍历每个集合，求出集合内元素的和 \( s_i \)，得到列表 `s`。
2. **计算三元乘积总和**：用上述 `sum_of_triple_products(s)` 即可。
3. **返回结果**。

```python
def solve(sets):
    # sets 是列表的列表，如 [[a1,a2], [b1,b2], [c1,c2], ...]
    s = [sum(one_set) for one_set in sets]
    return sum_of_triple_products(s)
```

**复杂度**：  
- 求所有 \( s_i \)：\( O(\sum |set_i|) \)  
- 求三元乘积和：\( O(n) \)  
整体为线性时间。

---

**备选公式（需要平方和、立方和）**

若你更喜欢用封闭公式，也可以先计算：
- \( S_1 = \sum s_i \)  
- \( S_2 = \sum s_i^2 \)  
- \( S_3 = \sum s_i^3 \)  

那么：
\[
\sum_{ i < j < k } s_i s_j s_k = \frac{S_1^3 - 3S_1 S_2 + 2S_3}{6}
\]
该公式与遍历法结果一致，但需要额外处理可能的大数溢出（Python 中整数自动支持大数，无需担心）。

### 双向哈希



#### 树上双向哈希
[牛客小白月赛91 G](https://ac.nowcoder.com/acm/contest/78807/G)
流程：先把“根到节点”和“节点到根”两个方向的字符串哈希预处理出来，再利用 LCA 把任意一条 \(u\to v\) 路径拆成“向上部分 + LCA + 向下部分”，最后利用哈希的定义重新拼起来
需结合LCA
维护2个数组
```cpp
vector<ull> down; //down[u] 表示根节点到 u 的路径的哈希值
```
在dfs过程中递推
已知 $down[fa] = Hash(root -> fa)$ ，要在**末尾**增加字符
根据 $Hash(Xc) = Hash(X)B + value(c)$ 得
```cpp
down[u] = getValue(s[u]) + down[fa] * base;
```

```cpp
vector<ull> up; //up[u] 表示 u 到根节点的路径的哈希值
```
$$
up[u] = \sum_{x \in u -> root}val(x) \times B^{deep[x]}
$$
在dfs过程中递推
已知 $down[fa] = Hash(fa -> root)$ ，要在字符串**开头**增加字符
根据 $Hash(cX) = value(c)B^{|X|} + Hash(X)$ 且 fa 到 root 的节点数为 $deep[fa] + 1 = deep[u]$ 得
```cpp
up[u] = getValue(s[u]) * power_base[deep[u]] + up[fa];
```

例如
```
        1(a)
        |
        2(b)
        |
        3(c)
        |
        4(d)
```
那么
up[1] = hash("a")
up[2] = hash("ba")
up[3] = hash("cba")
up[4] = hash("dcba")
down[1] = hash("a")
down[2] = hash("ab")
down[3] = hash("abc")
down[4] = hash("abcd")

要求出路径 u -> v 的哈希值
设
```cpp
int lca = getLCA(u, v);
int len1 = deep[u] - deep[lca], len2 = deep[v] - deep[lca];
```
整个路径可以拆成 $u -> lca + lca + lca -> v$
求左半条路径 $u -> lca$ 的哈希值
$$
left &= \sum_{x \in u -> lca}val(x) \times B^{deep[x]}
    &= Hash(u -> child(lca)) \times B^{deep[lca] + 1}
$$
```cpp
ull left = up[u] - up[lca];
```
注意此处整体多乘了一个 $B^{deep[lca] + 1}$，可以在模 $2^64$ 意义下除去，也可以如后文给其余部分也乘上

求右半条路径 $lca -> v$ 的哈希值
$$
right = Hash(child(lca) -> v)
$$
```cpp
ull right = down[v] - down[lca] * power_base[len2];
```
左右处理方式不同的原因是定义 up 和 down 时使用的不是同一种坐标系
down 是普通一维字符串哈希，可以直接用 $down[v] - down[lca]B^{len2}$
而 up 的幂次和其在整棵树里的绝对深度有关，因此 $up[u] - up[lca] = Hash(u -> child(lca))B^{deep[lca]}$，而不是单纯的 $Hash(u -> child(lca))$

假设
```
          x
          |
          d
        /   \
       c     e
       |     |
       b     f
       |
       a
```
查询 u = a, v = e
路径是 a -> b -> c -> d -> e -> f
lca = d
len1 = 3, len2 = 2
则
$$
left &= up[u] - up[lca]
    &= aB^{deep[d] + 3} + bB^{deep[d] + 2} + cB^{deep[d] + 1} + dB^{deep[d]} + x - dB^{deep[d]} - x
    &= (aB^{3} + bB^{2} + cB^{1}) \times B^{deep[d] + 1}
    &= Hash("ab") \times B^{len2}
$$

$$
right &= 
    &= dB^{1} + e
$$

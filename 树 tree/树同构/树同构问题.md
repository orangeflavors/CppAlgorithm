### 树同构（Tree Isomorphism）问题
判断两棵子树是否形状相同（忽略节点值，只看拓扑结构）
核心方法：树哈希（Tree Hashing）

1. 最常用的 AHU 算法 / 括号序列

对有根树进行 DFS，将子树结构编码为字符串：

```cpp
// 返回子树的括号序列表示
string dfs(int u, int parent) {
    vector<string> children;
    for (int v : adj[u]) {
        if (v != parent) {
            children.push_back(dfs(v, u));
        }
    }
    sort(children.begin(), children.end());  // 排序保证同构子树得到相同串
    string hash = "(";
    for (auto &s : children) hash += s;
    hash += ")";
    return hash;
}
// 两子树同构 ⇔ dfs(u1, -1) == dfs(u2, -1)
```

时间复杂度 O(n log n)（受排序限制），空间可能较大（字符串拼接）。

2. 基于哈希值的整数编码（推荐）

给每种子树形状分配唯一整数 ID：
```cpp
map<vector<int>, int> shape_id;  // 子节点形状列表 → 形状ID
int cnt = 0;

int get_hash(int u, int parent) {
    vector<int> children_hashes;
    for (int v : adj[u]) {
        if (v != parent) {
            children_hashes.push_back(get_hash(v, u));
        }
    }
    sort(children_hashes.begin(), children_hashes.end());
    if (!shape_id.count(children_hashes)) {
        shape_id[children_hashes] = ++cnt;
    }
    return shape_id[children_hashes];
}
// 两子树同构 ⇔ get_hash(u1, -1) == get_hash(u2, -1)
```

时间 O(n log n)，比字符串拼接高效得多。cnt 最终等于不同形状的数量。

3. XOR / 素数哈希（更快但可能有碰撞）

```cpp
using ull = unsigned long long;
const ull BASE = 131; // 或大质数如 1000000007

ull dfs_hash(int u, int parent) {
    ull h = 1;
    for (int v : adj[u]) {
        if (v != parent) {
            h *= (dfs_hash(v, u) ^ BASE);
        }
    }
    // 或者用子哈希的排序后组合
    return h;
}
```
可以结合双哈希防碰撞。

4. 无根树同构（AHU 完整版）

如果比较的是无根树（不指定根），需要先找树的重心作为根，再对每个重心做上述哈希。重心最多 2 个，比较时取 min
或同时比较。

```cpp
// 找重心
vector<int> find_centroid(int n) {
    vector<int> sz(n), centroids;
    function<void(int,int)> dfs = [&](int u, int p) {
        sz[u] = 1;
        int max_sub = 0;
        for (int v : adj[u]) if (v != p) {
            dfs(v, u);
            sz[u] += sz[v];
            max_sub = max(max_sub, sz[v]);
        }
        max_sub = max(max_sub, n - sz[u]);
        if (max_sub <= n / 2) centroids.push_back(u);
    };
    dfs(0, -1);
    return centroids;
}
```

竞赛中最常用的就是第2种方法（子哈希排序后去重分配ID），零碰撞且常数小。
